# 交互规格：触屏 → 桌面

原包是 Android 平板应用，交互以触摸为主。移植到键鼠后**不能原样照搬**：
手势没有等价物，就必须给出桌面语义；而桌面本来就有、且用户已经形成肌肉记忆的操作，
必须保留而不是被应用截胡。

本文件是这份映射的唯一来源。实现层（`packages/ui/src/replica/`、`packages/modules/`）
按本表实现，新增交互先改这里。

## 一、等价映射

| 原包手势 | 桌面等价 | 说明 |
| --- | --- | --- |
| 点按 | 左键单击 | 直接对应 |
| 长按 | 右键 | 长按菜单改由右键唤出 |
| 双击 | 双击 | 播放页双击画面切全屏 |
| 左右滑动（播放器） | 拖动进度条 / `←` `→` / `Shift+滚轮` | 三种入口都要有 |
| 上下滑动右半屏（音量） | 滚轮 | 播放页滚轮直接调音量 |
| 上下滑动左半屏（亮度） | `Alt+滚轮` | 桌面有系统亮度，默认不改；`Alt+滚轮` 走应用内遮罩 |
| 双指缩放 | `Ctrl+滚轮` | 交给浏览器/系统缩放，应用不截胡 |
| 下拉刷新 | `F5` | 各页提供可见的「刷新」按钮作为发现入口 || 返回手势 | `Alt+←` / 鼠标侧键 / `Esc` | 播放页 `Esc` 返回列表 |
| 底部标签 | 底部标签 + `1` `2` `3` | 保留原布局，补数字键 |
| 音量键 | `↑` `↓` | |
| 全屏键 | `F` / 双击画面 | |

## 二、桌面必须新增、原包没有的

| 操作 | 入口 | 理由 |
| --- | --- | --- |
| 聚焦搜索 | `Ctrl+F` | 桌面习惯；不抢浏览器语义之外的东西 |
| 右键菜单 | 卡片 / 列表项右键 | 播放、复制链接、复制标题、下载、不感兴趣 |
| 复制链接 | 右键 / `Ctrl+C`（选中卡片时） | |
| 新窗口打开 | 右键 / `Ctrl+点击` | |
| 悬停反馈 | 卡片悬浮抬升 + 封面播放角标 | 触屏没有 hover，桌面必须有 |
| 键盘遍历 | `Tab` / `Shift+Tab` | 所有可点元素保持可聚焦 |
| 快捷键说明 | `F1` | 发现性入口 |
| 拖拽排序 / 多选 | `Ctrl+点击` | 下载队列用，见「五、刷新与多选的落地位置」 |
| 滚动到顶 | `Home` / `Ctrl+Home` | |

## 三、明确的取舍（不做）

| 不做 | 原因 |
| --- | --- |
| 还原 Android 状态栏 | 那是系统 UI，不是应用 UI |
| 还原手势条 / 虚拟导航键 | 同上 |
| 单指滑动切 Tab | 与横向滚动冲突，桌面无此预期 |
| 双击点赞 | 与双击全屏冲突，保留双击全屏 |
| 屏蔽 `Ctrl+滚轮` 缩放 | 系统级预期，不该被应用覆盖 |

## 四、播放器按键表

| 按键 | 行为 |
| --- | --- |
| `Space` / `K` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进 5 秒（步长可在模块设置里改） |
| `Shift+←` `Shift+→` | 倍速 −/+ |
| `↑` `↓` | 音量 +/− 5% |
| `M` | 静音开关 |
| `F` | 全屏开关 |
| `D` | 弹幕开关 |
| `,` `.` | 逐帧步进 |
| `0`–`9` | 跳转到 0%–90% |
| `Alt+S` | 截图 |
| `Esc` | 退出全屏 / 返回列表 |

鼠标：

| 操作 | 行为 |
| --- | --- |
| 单击画面 | 播放 / 暂停 |
| 双击画面 | 全屏开关 |
| 滚轮 | 音量 |
| `Shift+滚轮` | 快进 / 后退 |
| 按住进度条拖动 | 任意跳转 |
| 悬停 | 显示控制条，3.2 秒后隐藏 |

## 五、键位冲突处理

1. 输入框获得焦点时，所有单键快捷键**全部让位**。
2. 涉及 `Ctrl` / `Meta` 的组合只使用浏览器未占用的（`Ctrl+F`、`Ctrl+C` 是刻意的，因为桌面语义就是它们）。
3. 播放页的 `Space` 等按键会 `preventDefault` 并 `stopPropagation`，避免被网页播放器重复处理。
4. 模块级快捷键（`packages/modules/src/shortcuts.ts`）与界面级快捷键（`Replica.vue`）
   作用域分离：前者只在 B 站页面窗口生效，后者只在客户端面板生效，两者不会同时收到同一次按键。

## 六、刷新与多选的落地位置

这两项都是桌面新增能力，统一入口，避免每个页面各写一套。

| 能力 | 派发方 | 响应方 |
| --- | --- | --- |
| `F5` 刷新 | `Replica.vue` 拦截并派发 `window` 事件 `bilihub:refresh` | 首页重载当前标签 + 热搜词；动态页重载动态流；我的页刷新账号信息 |
| 可见刷新按钮 | — | 首页顶栏图标组、我的页右栏头部；动态页头部已有的「刷新」按钮 |

下载队列多选（`ExtendPanel.vue`）：

| 操作 | 效果 |
| --- | --- |
| 单击任务卡 | 单选；再次点击同一张取消选择 |
| `Ctrl` / `⌘` + 单击 | 叠加或取消单项 |
| 批量栏 | 全部暂停 / 全部继续 / 批量移除 / 取消选择 |

> 为什么用 `F5` 而不是自己的刷新键：下拉刷新在桌面没有等价手势，
> 而 `F5` 是用户已有的肌肉记忆。但同时必须提供可见按钮，
> 否则只有知道快捷键的人才能刷新。
